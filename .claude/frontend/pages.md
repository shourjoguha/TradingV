# Pages

20 routes. All under `src/pages/`. Routing in `src/App.tsx`.

> **IA reorg Phases 1-3 (2026-05-08).** Today replaces Dashboard as `/`. Legacy Dashboard moves to `/admin/overview`. Sidebar regrouped: **Today** / **Decide** (Signals/Predictions/Macro/Watchlist) / **Think** (Research/Theses/TV Context/The Street) / **Admin** (collapsed by default) / **Docs**. Tabs: **Processes** (default) / **Cadences** / **Costs** / **Retention** / **Schedule** (existing form) / **Jobs** (existing analysis jobs + detail). ## Conventions

- All pages use TanStack Query hooks from `hooks/use-api.ts`. No direct fetch.
- Loading state: `<Skeleton />` from `components/ui/skeleton.tsx`.
- Empty state: text in muted-foreground, not a separate page.
- Dates: send/receive ISO `YYYY-MM-DD`. Convert to local tz at display only.
- Day-of-week filter: Mon=0..Sun=6 (Python convention). Tooltip in UI clarifies.

## Layout

`Layout.tsx` wraps everything: 224px sidebar (nav + Kronos logo + `HypothesisStatusWidget`), 56px topbar (breadcrumb + `BackendToggle`), scrollable content area max-width 7xl.

`NAV_GROUPS` (Phases 1-3 IA reorg) groups by user-job not backend-module:

```
Today                       /             Sun           leaf
Decide                      group         LineChart     Signals/Predictions/Macro/Watchlist
Think                       group         Brain         Research/Theses/TV Context/The Street
Admin (collapsed default)   group         Zap           Schedule/Health/Legacy Dashboard
Docs                        /docs         BookOpen      leaf
```

Admin defaults to collapsed via the `defaultCollapsed = group.id === 'admin'` branch in `NavSection` — operator's manual expand/collapse persists via `localStorage('sidebar.collapsed.<group_id>')`.

`HypothesisStatusWidget.tsx` sits at the bottom of the sidebar (both desktop + mobile drawer): inset-card with `active` count + `at_risk` count when > 0. Hides itself when total = 0 so it's invisible until the first hypothesis is seeded. M-2 minimum-viable surface — no full `/hypotheses` page yet (operator decision: defer until ≥10 active rows justify a card grid).
